# Práctica de Funciones en TypeScript + React

Proyecto con los diez ejercicios solicitados en las plantillas base: calculadora, conversor de temperatura, calculadora de IMC, validador de edad, analizador de texto, estadísticas de arreglo, generador de contraseñas, aplicador de descuentos, sistema de calificaciones y carrito de compras.

## Requisitos
- Node.js LTS y npm.
- Visual Studio Code (recomendado).

## Ejecutar el proyecto
1. Descomprime el archivo ZIP y abre la carpeta `PracticaFuncionesTSReact` en VS Code.
2. Abre la terminal integrada (`Terminal > Nueva terminal`).
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.
5. Abre en el navegador la dirección local que muestre Vite (normalmente `http://localhost:5173`).
6. Para verificar la compilación de producción, ejecuta `npm run build`.
